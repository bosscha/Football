# Football Simulation & Analytics

Bayesian and Monte Carlo probability simulations on football tournaments and leagues.

## Projects

- **[UEFA Champions League 2026/27 Simulation (`ucl_2627_sim/`)](ucl_2627_sim/)**: High-performance Monte Carlo simulation engine written in Rust simulating 1,000,000 seasons of the 36-team single league phase with Poisson expected goals, official UEFA tiebreaker sorting, full 144 fixtures calendar, and comprehensive publication PDF reports.
- **[WFC 2026 Simulation (`WFC26/`)](WFC26/)**: World Football Championship 2026 simulation and tournament modeling in Julia.
